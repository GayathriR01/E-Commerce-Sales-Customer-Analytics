# 🛒 E-Commerce Sales & Customer Analytics

A desktop-based E-Commerce Management System developed using **Python, Tkinter, and SQLite** to manage products, customers, orders, and sales data. The project also includes a sales analytics dashboard designed to monitor business performance and support data-driven decisions.

## 📌 Project Overview

The E-Commerce Sales & Customer Analytics project provides a simple interface for customers and administrators to manage online shopping activities and business operations.

Customers can register, log in, browse available products, place orders, and view their order history. Administrators can manage products, view registered customers, monitor orders, and export order data as a CSV dataset for further analysis using tools such as Microsoft Power BI.

## ✨ Key Features

### 👤 Customer Module
- Customer registration and login.
- View available products, categories, prices, and stock.
- Place orders by selecting products and quantities.
- Automatic order total and profit calculation.
- Stock quantity updates after placing an order.
- View personal order history and order status.
- Customer information management through registration details.

### 🔐 Admin Module
- Administrator registration and login.
- Add and manage products.
- View product details, selling prices, cost prices, profit per unit, and stock.
- View registered customer details.
- Monitor customer orders, quantities, totals, profits, and statuses.
- Delete products from the inventory.
- Export order-related data to CSV format.
- Access business information through an admin dashboard.
